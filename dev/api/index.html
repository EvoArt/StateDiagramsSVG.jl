StateDiagramsSVG.Diagram — Type
Diagram

Canvas of drawing primitives, rendered by svg, tikz, cetz or makiefigure. Origin top left, y down.

Fields: width, height, title, description (SVG accessibility text).

StateDiagramsSVG.state_diagram — Method
state_diagram(source; title="State transition model", subtitle="", width=1200) -> Diagram

Lay out a state model written in a line-based language (# starts a comment):

state A: Name                       # at most five main states, left to right
A -> B: event | probability         # must follow declaration order
A, B -> C: event | probability      # shared destination, drawn as a bus
entry: text
note: text
section NAME [wide]: line | line | line

Any label may carry a TeX form after ~, e.g. s p_SE ~ $s p_{\mathrm{SE}}$; tikz uses it verbatim, other backends the plain form. TeX is not escaped: use trusted input. Throws ArgumentError on invalid input.
